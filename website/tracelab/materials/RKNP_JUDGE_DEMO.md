# TraceLab — 3 minute judge demo

## 0:00–0:25 — Problem
Show one real team project folder / GitHub / CAD / photo history and ask: **where is the reason for this engineering decision?**

Core line: **The files survive. The reason disappears.**

## 0:25–0:55 — Capture
Open TraceLab Capture. Show that a source event is already known and the student is asked only for the missing human engineering context.

Key point: TraceLab does not ask students to rewrite work that GitHub/CAD already knows.

## 0:55–1:35 — Trace Replay
Open Engineering Timeline and press **Replay**. Let real stored evidence move through Source → Iteration → Test → Decision.

Key point: this is not decorative animation; each step is a stored record or relation.

## 1:35–2:05 — Why?
Open a decision and ask Why?. Show the linked test, original revision, and student-authored rationale.

Key point: deterministic retrieval first; if evidence is absent TraceLab says it is not documented instead of inventing a reason.

## 2:05–2:35 — Research proof
Open `/app/research`. Explain the measurable outcomes and the live process indicators. Then show the separate before/after dataset from the pilot.

Never present current team-health metrics as proof of causal improvement.

## 2:35–3:00 — Trust and impact
Show Competition Mode / policy restrictions and cross-season handoff.

Closing line: **TraceLab preserves not only what students built, but the evidence of how and why they built it.**
