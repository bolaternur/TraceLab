# Iznera — смена названия проекта

28 октября 2026 года владелец выбрал название **Iznera** вместо прежнего **TraceLab** и предоставил логотип. Видимое название обновлено в публичных страницах, рабочей области, регистрации и входе, письмах, отчётах, локализации RU/EN/KK, метаданных приложения и руководствах. Логотип используется как предоставленный владельцем брендовый материал; правовая проверка имени, домена или изображения этой записью не подтверждается.

Оригинал владельца сохранён в `assets/brand/iznera-original.png`. Прозрачная версия для интерфейса — `public/brand/iznera-logo.png`; фон удалён встроенным ImageGen с сохранением предоставленной формы и цветов. Компактный векторный знак для вкладки и узких панелей находится в `public/brand/iznera-mark.svg`. Название и графика встраиваются в новые HTML/PDF-отчёты; исходный файл логотипа сохраняется отдельно.

Уточнённый прозрачный файл, повторно присланный владельцем, сохранён без изменений в `assets/brand/iznera-transparent-original.png` и используется для версии в интерфейсе. CSS-подложка удалена; прозрачность PNG сохранена. После этого уточнения production build, 90 статических проверок и ESLint компонента прошли; в браузере фон обеих `.a-brand` равен `rgba(0, 0, 0, 0)`.

Логотип размещается с прозрачным фоном прямо на существующей поверхности сайта. По уточнению владельца белая плашка, светлая подложка и рамка вокруг знака не добавляются. Размеры изображения и область нажатия сохраняются.

## Совместимость существующих данных

| Сохраняемый идентификатор | Причина |
| --- | --- |
| PostgreSQL `tracelab_unified_*`, роли `tracelab_*`, схема `tracelab_legacy` | Действующие подключения, зарегистрированные миграции и данные команд сохраняются. Переименование не требует пересоздания базы или seed. |
| Браузерные storage/IndexedDB/outbox ключи и события `tracelab:*` | Существующие проекты, расположения, очередь офлайн-записей и выбор языка должны остаться доступны. |
| Форматы резервных копий и исходные технические поля | Старые JSON/CSV продолжают импортироваться; смена вывески не переписывает инженерные записи и авторство. |
| `X-TraceLab-Queue-Owner` | Согласованный контракт очереди клиента и сервера, защищающий принадлежность отправки аккаунту. |
| Исследовательское условие CSV `tracelab` и поле сводки `summary.tracelab` | Старые измерения остаются читаемыми. Новые шаблоны используют `iznera`; оба значения распознаются как одно условие исследования. |
| Папки `website/tracelab`, `src/components/tracelab` и локальный checkout `C:/Users/User/projects/TraceLab-web` | Импорты, сценарии запуска, локальные вложения и существующие ссылки не меняются ради отображаемого имени. |
| Репозиторий `https://github.com/bolaternur/TraceLab` и исторические архивы | Это реальные существующие адреса и имена файлов. Ссылка не заменяется выдуманным репозиторием. |

Новые файлы отчётов получают префикс `iznera-`, вложенный манифест PDF — `iznera-manifest.json`. Уже сохранённые или скачанные файлы не переименовываются задним числом. Исторические пути и имена источников в документах сохранены дословно.

Учётные записи, действующие сессии, команды, коды приглашений, проекты, приватные файлы и миграции не сбрасываются. Переименование не публикует сайт, не создаёт новый домен и не включает внешнюю доставку писем.

## Проверки реализации

`npm test`: 109 passed, 57 DB opt-in skipped; отдельный `npm run test:db`: 57 passed, 0 skipped. `npm run test:static`: 90 passed, включая название и ресурсы логотипа на всех публикуемых маршрутах. Три проверки исследовательского CSV включают совместимость старого и нового названия. TypeScript, ESLint и production build прошли.

В браузере проверены главная, форма аккаунта, локализация RU/KK, загрузка логотипов и существующий командный проект с ранее загруженной 3D-моделью. Старое окно с уже созданным кодом приглашения не перезагружалось. Смена viewport в доступном браузере не применилась, поэтому отдельная проверка на физическом телефоне остаётся приёмкой; мобильные стили логотипа включены. Два брендовых frontend-contract assertions проходят; полный исторический frontend-contract набор содержит прежние несвязанные ожидания и не объявляется пройденным.
