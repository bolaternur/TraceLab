# Внешние сервисы: настройка владельцем

Реальные аккаунты провайдеров и ключи в этой работе не создавались. Локальный TraceLab работает без них. Не отправляйте секреты в чат и не добавляйте их в GitHub.

## Почта — Resend

Зарегистрируйтесь на https://resend.com, добавьте свой домен отправителя и выполните предложенную сервисом проверку DNS. Создайте ключ с правом отправки для нужного домена. Полная последовательность, проверки и ограничения: [account-mail-setup.md](account-mail-setup.md).

Локально: `MAIL_TRANSPORT=local`, `MAIL_PREVIEW_ENABLED=true`. Для реального окружения: `MAIL_TRANSPORT=resend`, `MAIL_ENABLE_EXTERNAL_DELIVERY=true`, `RESEND_API_KEY`, `MAIL_FROM` и точный HTTPS `APP_URL`. `MAIL_PREVIEW_ENABLED=false` в production. После настройки проверьте регистрацию, доставку, одноразовость ссылки, истечение срока, повторную отправку и сброс пароля на собственном тестовом адресе. До такой проверки нельзя писать «реальные письма работают».

## Файлы — Supabase Storage

1. Зарегистрируйтесь на https://supabase.com и создайте проект в подходящем регионе.
2. В Storage создайте **private**, а не public bucket, например `tracelab-private`. Не включайте публичное чтение.
3. На сервере добавьте `STORAGE_PROVIDER=supabase`, `SUPABASE_URL=https://<project>.supabase.co`, `SUPABASE_SERVICE_ROLE_KEY=<server-only key>`, `SUPABASE_STORAGE_BUCKET=tracelab-private`.
4. Перезапустите TraceLab. Загрузите безличную тестовую фотографию в отдельной команде, откройте миниатюру и скачайте файл. Повторите с GLB.
5. Убедитесь, что другой аккаунт вне команды не может получить файл и что доступ исчезает после отзыва членства. Попытка использовать публичный bucket должна завершаться ошибкой.

Адаптер обращается к private Storage API только с сервера. Клиент получает авторизованный маршрут TraceLab; ключ не передаётся браузеру. Внешняя конфигурация не проверена настоящим аккаунтом в этой работе — тесты адаптера используют подменённый транспорт.

Не переключайте провайдер поверх действующей библиотеки без плана переноса: существующие файлы не копируются автоматически. Сначала сделайте резервную копию БД и файлов, перенесите объекты с сохранением ключей и контрольных сумм, проверьте их доступность, затем переключайте окружение. Локальный вариант использует `STORAGE_PROVIDER=local` и постоянный приватный `STORAGE_ROOT`.

## База и публикация

Настройте PostgreSQL отдельно от Storage. `DATABASE_URL` — ограниченная роль приложения; `DATABASE_MIGRATION_URL` — роль для миграций. Сохраните случайный `SECRETS_ENCRYPTION_KEY` длиной не менее 32 символов; потеря/самовольная смена ключа делает существующие зашифрованные данные недоступными. Используйте HTTPS, резервное копирование, ограниченный доступ к журналам и отдельное тестовое окружение.

Подключение домена, DNS, production, платёжных сервисов и рассылок здесь не выполняется. TraceLab остаётся бесплатным; провайдеры инфраструктуры могут иметь собственные лимиты и стоимость.
