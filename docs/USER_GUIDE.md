# TraceLab — руководство рабочей версии

Полные руководства по каждому разделу и трём практическим маршрутам: [Русский](USER_GUIDE_RU.md) · [English](USER_GUIDE_EN.md) · [Қазақша](USER_GUIDE_KK.md). Эта страница — краткое введение. Проверка переводов носителем языка ещё не завершена.

## Начало работы

1. Откройте `http://localhost:3000` и выберите «Создать команду бесплатно».
2. Введите имя, почту и пароль. В локальном режиме откройте «Локальный ящик тестовых писем», перейдите по ссылке и подтвердите адрес. Письмо остаётся на компьютере.
3. Войдите. Создайте команду, проект, сезон и выберите часовой пояс. Новый проект пуст: в него не добавляются учебные результаты.
4. Если вам передали приглашение, используйте его вместо создания второй команды. Ссылка предназначена только для выбранного участника.

## Материал → испытание → решение

Кнопка «Добавить запись» открывает форму. Запишите наблюдение своими словами. При добавлении испытания укажите процедуру, одинаковые условия, критерий и результат. Число успешных попыток не может превышать число всех попыток.

Для решения выберите «Черновик», пока объяснение не готово. Завершённое решение требует ответа «Почему». Выберите существующую запись, чтобы добавить направленную связь вместе с новой записью. Имя автора берётся из аккаунта; введённая авторская формулировка не генерируется и не переписывается системой.

В графе можно перемещать карточки, менять масштаб, открывать подробности и удалять ошибочную связь. Изменение расположения не меняет инженерное содержание. Хронология показывает свежие записи первыми и группирует их по дням в часовом поясе команды. Поиск, тип записи и выбранный раздел доступны в адресе страницы.

## Галерея и 3D-модели

Откройте «Галерея» или «3D-модели» в левой панели. Загружайте собственные файлы через форму. Поддерживаются JPEG/PNG/WebP, документы PDF/CSV и самостоятельные GLB в пределах указанных интерфейсом лимитов. Фото нормализуются с удалением метаданных; перед отправкой можно скрыть чувствительную область. PDF и CSV выдаются как файлы, а не исполняемый код.

Модели делятся на робота, сборку и деталь. Новая версия не заменяет файл предыдущей версии. Просмотрщик работает с настоящими GLB; STEP/OBJ, ссылки на внешние текстуры и неподдерживаемые форматы не изображаются как успешно загруженная модель. При недоступном WebGL скачайте исходный файл или используйте другое устройство.

## Без интернета

В меню «Проект» откройте «Быстрая запись · офлайн». Сначала нужно хотя бы раз войти и открыть нужный проект при соединении. Новая запись сохраняется в очереди этого аккаунта на устройстве; надпись о локальном сохранении не означает доставку в команду.

Для фотографии выберите тип «Фото», затем файл или «Снять фото». Поддерживаются JPEG, PNG и WebP до 15 MiB. Файл и подпись сохраняются вместе в IndexedDB до сообщения об успехе; перезагрузка страницы не создаёт новую отправку. В очереди допускается до 100 записей на аккаунт и до 60 MiB фотографий на устройство. Оригинал фото, включая возможные метаданные, временно хранится в этом браузере. Сервер удаляет EXIF/GPS при отправке в команду; офлайн-редактор фото здесь не обещается.

После восстановления связи нажмите «Отправить в команду»; открытая страница также повторяет отправку при появлении сети. Очередь удаляет запись только после успешного ответа сервера. При истёкшей сессии войдите в тот же аккаунт. Если членство отозвано, черновик останется на устройстве. JSON скачивает текстовые записи и перечень фото, но не байты изображений: у каждого фото есть отдельная кнопка скачивания. Удаление локального черновика требует подтверждения.

Не очищайте данные браузера, пока не отправили или не сохранили копии черновиков. Эти данные относятся к профилю браузера; локальная очередь не является зашифрованным сейфом или серверной резервной копией. Редактирование существующих записей, файлы PDF/CSV/GLB и отправка при полностью закрытом приложении в этот офлайн-сценарий не входят. Проверка на физическом мобильном устройстве после перезапуска остаётся отдельной задачей.

## Старые проекты и перенос

Браузерный учебный режим доступен по `/demo/workspace`. Он использует прежний формат локальных проектов. В меню командного проекта выберите перенос проекта этого браузера либо импорт JSON. Проверьте количество записей, связей, предупреждения и целевую команду, затем подтвердите перенос. Создаётся отдельный проект, исходные данные не удаляются. Метки вымышленных исходных данных и непроверенного авторства сохраняются.

При одновременной правке другим участником сервер сохраняет конфликтующую версию как предложение. Откройте историю записи, сравните версии и согласуйте правку; автоматического объединения нет. При сетевой ошибке текст остаётся в форме: не считайте его сохранённым без подтверждения сервера.

## Отчёты и исследование

В меню проекта откройте «Отчёт PDF / HTML», проверьте предупреждения, формат и размер страницы. Обычный инженерный отчёт переносит сохранённые объяснения и содержит сведения о происхождении. Конкурсный режим требует отдельной проверки актуальных правил; наличие PDF само по себе не подтверждает допустимость подачи.

Раздел «Замеры» предназначен для сопоставимых пар измерений одного участника. Используйте код вместо имени. CSV импортируется целиком после проверки. Учебные цифры не доказывают эффект TraceLab и не заменяют реальные результаты пилота.

## Язык и данные

Переключатель RU / EN / KK меняет интерфейс, а не тексты авторов. Для резервного копирования командных данных нужны база и файлы вместе. JSON помогает переносить структурированные записи, но не заменяет резервную копию двоичных файлов. Подключение Resend, Supabase, внешних источников, публикация и пилот требуют отдельных действий владельца.

Точные результаты проверок и незавершённые требования: `IMPLEMENTATION_MATRIX.md`. Эта инструкция описывает текущие сценарии, а не подтверждение готовности к публичному запуску.
