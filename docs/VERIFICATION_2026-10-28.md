- Общие записи обновляются по revision feed каждые 5 секунд в видимом свободном интерфейсе. Открытые формы, ввод и перенос узлов не прерываются. Неизменившийся проект не перерисовывается; запись, начатая во время опроса, не заменяется старым ответом. Это синхронизация сохранённых записей, без одновременного редактирования символов.
- Подготовлена проверка настроек пилота, миграций и ограниченной роли PostgreSQL; CI использует свежую базу без seed. Добавлен защищённый планировочный endpoint отправки писем с ограниченными повторами.
- HTTPS proxy поддерживается только при явном доверии, совпадении публичных host/protocol и обязательном точном browser Origin. Неверный Origin/host отклоняется. Сетевой rate limit использует проверенный proxy suffix; подставленный клиентом префикс не выбирается как IP.

## Дополнение: локальное подтверждение аккаунта

Локальный транспорт не отправляет письма во внешнюю почту. Форма теперь сообщает об этом рядом с полями, автоматически находит действующее подтверждение после signup/resend и показывает кнопку «Подтвердить аккаунт здесь». Со страницы входа можно перейти к этому действию, сохранив введённый адрес. Кнопка использует обычный одноразовый verify endpoint; пароль и производственная проверка почты не обходятся. После подтверждения пользователь входит со своим паролем.

Просмотр ссылок ограничен development, loopback, точным origin и HttpOnly mailbox этого браузера. POST дополнительно фильтрует введённый адрес и назначение; использованные, заменённые и просроченные токены не возвращаются. В production и GET, и POST недоступны. Локальный reset остаётся отдельной ссылкой для самостоятельного выбора пароля пользователем.

Повторные проверки после исправления: `npm test` — **109 passed / 57 skipped**; `npm run test:db` — **57 passed / 0 skipped**. TypeScript, ESLint и production-сборка прошли. Новые тесты включают 9 HTTP-проверок границ preview, 2 проверки безопасных ссылок и PostgreSQL-проверку изоляции браузера/адреса/назначения и действительности токенов. В браузере проверены переход со входа, запрос локальной ссылки и появление кнопки; подтверждение реального аккаунта и ввод пароля оставлены пользователю. Снимок с адресом пользователя хранится только локально и в Git не включён.
