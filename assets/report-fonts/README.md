# Report font

Noto Sans variable TrueType font from the official Google Fonts repository:
https://github.com/google/fonts/blob/main/ofl/notosans/NotoSans%5Bwdth%2Cwght%5D.ttf

Retrieved 2026-10-26; distributed under the SIL Open Font License 1.1 in OFL.txt.
The downloaded font has been checked with fontkit for Latin, Russian and all
Kazakh-specific letters ӘҒҚҢӨҰҮҺІ and their lowercase forms. PDFKit embeds only
the glyphs used by each generated report. This is a server asset, not a web font.
